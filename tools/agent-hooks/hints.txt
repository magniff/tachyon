# Texts the agent hooks add to the agent's context (0.17;
# docs/research/applying-to-vole.md, items 7 and 9;
# .claude/briefs/research/delivery.md, E3/E5/E6). One text a line:
# `KEY: TEXT`; `#` starts a comment. Each is a factual statement with the
# command in it (no instruction framed as a system message: those can
# read as a prompt injection), short, and the same words every time (no
# times or ids: appended text is paid once, then read from the cache).
# In TEXT, {NAME} is the item the agent asked about, {VOLEC} the
# compiler it ran (`volec`, `target/volec`, `target/tools/volec`).
#
# repeat-query: after the third `query show`, `refs`, `def` or `callers`
# in a row on related items (the same name, a name and its type or
# module, a name the previous answer printed); once a session, never
# after a `query context`. VOLE_HINTS=0 turns it off.
repeat-query: note: `{VOLEC} query context {NAME}` prints in one call what show, refs and def print about {NAME}: its source, the items it uses, its callers
#
# unfamiliar-construct: after the same compile error (its code and words)
# twice in a session, or an error whose help names a guide topic; once a
# session. VOLE_HINTS=0 turns it off.
unfamiliar-construct: note: `{VOLEC} guide --find WORDS` prints the guide's lines on WORDS (an error's own words work); `{VOLEC} guide TOPIC#SECTION` prints one section
#
# rewritten: query-first in rewrite mode (VOLE_QUERY_MODE=rewrite),
# with the tool result of a read it ran as a query; {FROM} the command,
# {TO} what ran, {WHY} one clause.
rewritten: note hook.query-first: `{FROM}` ran as `{TO}`: {WHY}
# rewritten-first: the same, the first time in a session, saying what the
# mode does (the condition's prompt says it too).
rewritten-first: note hook.query-first: shell reads of large .vl files are answered with the matching query (sed -n, head, tail: `query text`; cat: `query items`; grep: `query refs` or `query grep`), each command of a line on its own, the others as typed; `{FROM}` ran as `{TO}`: {WHY}
# rewritten-also: each further command of the line run as its query.
rewritten-also: note hook.query-first: also `{FROM}` ran as `{TO}`: {WHY}
#
# repeat-lookup: lookup-note.py, when a guide, query, explain or --help
# call prints what the same call printed earlier in the session; once
# per call.
repeat-lookup: note: `{WHAT}` printed the same text at shell call {N} of this session
