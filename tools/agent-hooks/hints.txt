# Hint texts for the agent hooks (0.17; docs/research/applying-to-tachyon.md,
# items 7 and 9), for the hooks to print as they are. One hint a line:
# `KEY: TEXT`; `#` starts a comment. In TEXT, {NAME} is the item the agent
# asked about and {TACHYONC} the compiler it ran (`tachyonc`,
# `target/tachyonc`, `target/tools/tachyonc`).
#
# repeat-query: after `query show`, `refs` or `def` on the same NAME three
# times in a row (any order), appended once per NAME and session.
repeat-query: hint: one call gives what show, refs and def gave about {NAME}: its source, what it calls and its callers: `{TACHYONC} query context {NAME}`
#
# unfamiliar-construct: after the same compile error message (its code and
# words) twice in a session, or an error whose help names a guide topic.
unfamiliar-construct: hint: before writing a construct you are unsure of, `{TACHYONC} guide --find WORDS` (the error's words) or `{TACHYONC} guide TOPIC#SECTION` prints the lines on it
