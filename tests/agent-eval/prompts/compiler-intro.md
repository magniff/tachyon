# The repository

The current directory is a copy of the repository of vole, a
self-hosted systems language: its compiler is written in vole
(`compiler/src/`), with its standard library (`compiler/std/`), docs
(`docs/`), guide (`compiler/guide/`) and test suite (`tests/`). The copy
is at a fixed commit, with one git commit of its own (`git diff` shows
your changes). `target/volec` is the compiler built from this tree as
it was given to you. Its AGENTS.md, the instructions for agents working
on it, follows.
