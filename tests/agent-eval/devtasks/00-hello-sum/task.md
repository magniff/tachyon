# Sum of integers

Write a program that reads integers from standard input, one per line,
and prints their sum followed by a newline.

- Each non-blank line holds one decimal integer, possibly negative
  (`-12`), with no other characters. Blank lines are ignored.
- The input may be empty: the sum is then `0`.
- The last line may or may not end with a newline.
- There can be up to 100 000 lines; every value and the sum fit in a
  signed 64-bit integer.

Example input:

```
3
-5
10
```

Output:

```
8
```
